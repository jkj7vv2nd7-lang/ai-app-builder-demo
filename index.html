Local AI App Builder

アイデアから、ローカルで動くアプリの試作品へ。

OllamaとローカルAIモデルが、要件整理・画面設計・HTML実装・QAを順に進める Windows対応のオープンソース開発エージェントです。

GitHubでソースを見る セットアップ手順

このページは案内用です

GitHub Pagesは静的ページを表示します。Python、Tkinter、OllamaのAIモデルはブラウザー上では動きません。 エージェントを使うには、ソースをPCへダウンロードし、PythonとOllamaを準備してローカルで起動してください。

開発の流れ

  1. PM
    要件整理
  2. 設計
    画面・操作
  3. 実装
    単一HTML
  4. QA
    確認・保存

最初の入力はラフな一文で大丈夫。エージェントが具体的な要件や受け入れ条件に整理します。

まずはローカルで起動

Python 3.9以降、Tkinter、Ollamaが必要です。初回は選んだモデルをダウンロードします。

ollama pull qwen2.5-coder:7b
git clone https://github.com/jkj7vv2nd7-lang/ai-app-builder-demo.git
cd ai-app-builder-demo
python .\app_gui.py

おすすめ自動ルーティングでは要件・設計にqwen3:8b、実装・QAに qwen2.5-coder:7bを使います。詳細は READMEをご覧ください。

プライバシーと公開について

生成リクエストはローカルOllamaへ送ります。モデルの初回取得には通信が必要です。 生成したアプリをGitHubへ公開するときは、公開リポジトリでHTMLとソースが誰でも見られるため、 内容を確認してから明示的に操作してください。
